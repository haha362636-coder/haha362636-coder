# 验证码邮件模板（复制粘贴到 Supabase）

博客的注册和找回密码现在用**验证码**，不用点链接了。
Supabase 默认的邮件里只有链接，没有验证码，所以要把下面三个模板换掉。

位置：Supabase → **Authentication** → **Emails** → **Templates**（有的版本叫 **Email Templates**）

改完每个模板都要点 **Save**。

---

## 1. Confirm signup（注册验证）

**Subject（标题）：**

```
【Bobs 的博客】你的注册验证码是 {{ .Token }}
```

**Body（正文，切到 Source / HTML 再粘贴）：**

```html
<div style="max-width:480px;margin:0 auto;padding:32px 24px;font-family:-apple-system,'PingFang SC','Microsoft YaHei',sans-serif;color:#1d2433">
  <h2 style="margin:0 0 12px;font-size:20px">欢迎来到 Bobs 的博客 👋</h2>
  <p style="margin:0 0 20px;font-size:14px;line-height:1.8;color:#4a5568">你正在注册账号，请在网页上输入下面的验证码：</p>
  <div style="font-size:34px;font-weight:700;letter-spacing:8px;text-align:center;padding:18px 0;background:#eef9fd;border-radius:12px;color:#0a6b8a">{{ .Token }}</div>
  <p style="margin:20px 0 0;font-size:12px;line-height:1.8;color:#8a94a6">验证码 10 分钟内有效。如果不是你本人操作，忽略这封邮件就行。</p>
</div>
```

## 2. Reset Password（找回密码）

**Subject（标题）：**

```
【Bobs 的博客】你的重设密码验证码是 {{ .Token }}
```

**Body（正文）：**

```html
<div style="max-width:480px;margin:0 auto;padding:32px 24px;font-family:-apple-system,'PingFang SC','Microsoft YaHei',sans-serif;color:#1d2433">
  <h2 style="margin:0 0 12px;font-size:20px">重设密码</h2>
  <p style="margin:0 0 20px;font-size:14px;line-height:1.8;color:#4a5568">你正在重设 Bobs 的博客的账号密码，请在网页上输入下面的验证码：</p>
  <div style="font-size:34px;font-weight:700;letter-spacing:8px;text-align:center;padding:18px 0;background:#fff6e6;border-radius:12px;color:#a0620a">{{ .Token }}</div>
  <p style="margin:20px 0 0;font-size:12px;line-height:1.8;color:#8a94a6">验证码 10 分钟内有效。如果不是你本人操作，说明有人输错了邮箱，忽略这封邮件就行，你的密码不会被改。</p>
</div>
```

## 3. Magic Link（补验证邮箱）

已经注册、但还没验证过邮箱的账号，在网页上点「发送验证码」时用的是这个模板。

**Subject（标题）：**

```
【Bobs 的博客】你的邮箱验证码是 {{ .Token }}
```

**Body（正文）：**

```html
<div style="max-width:480px;margin:0 auto;padding:32px 24px;font-family:-apple-system,'PingFang SC','Microsoft YaHei',sans-serif;color:#1d2433">
  <h2 style="margin:0 0 12px;font-size:20px">验证你的邮箱</h2>
  <p style="margin:0 0 20px;font-size:14px;line-height:1.8;color:#4a5568">请在 Bobs 的博客网页上输入下面的验证码，验证后就能评论了：</p>
  <div style="font-size:34px;font-weight:700;letter-spacing:8px;text-align:center;padding:18px 0;background:#eef9fd;border-radius:12px;color:#0a6b8a">{{ .Token }}</div>
  <p style="margin:20px 0 0;font-size:12px;line-height:1.8;color:#8a94a6">验证码 10 分钟内有效。如果不是你本人操作，忽略这封邮件就行。</p>
</div>
```

---

## 4. 验证码有效期（可选）

**Authentication** → **Sign In / Providers** → **Email** 里有一项 **Email OTP Expiration**（验证码有效期，单位秒）。建议填 `600`（10 分钟），和邮件里写的一致。

同一页还有 **Email OTP Length**（验证码位数），保持默认的 6 位就行。网页能识别 6～10 位。
